# Headphones Website

This project is part of the **ALX Front-End Specialization**.  
It focuses on building a responsive landing page for a fictional headphone company using **HTML and CSS**, following a provided **Figma design**.

---

## 🧠 Learning Objectives

By the end of this project, you should be able to:

- Understand and read **Figma design files**
- Recreate a webpage from a **Figma mockup**
- Implement **responsive design** using media queries
- Use **semantic HTML** and clean **CSS structure**
- Maintain consistent typography, colors, and layout

---

## 🧩 Features

- Responsive design that adapts to screen size:
  - **Desktop layout** for screens wider than 480px
  - **Mobile layout** for screens 480px and below
- Custom hover effects:
  - Links hover/active color: `#FF6565`
  - Buttons hover/active: `opacity: 0.9`
- Centralized content with a max width of **1000px**
- Clean, modern layout based on **Figma prototype**
