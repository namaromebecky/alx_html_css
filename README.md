# Headphones Website

This project is part of the **ALX Front-End** course.  
The goal is to recreate a **responsive landing page** for a headphones company using **HTML and CSS**, following a Figma design.

---

## 🎧 Project Overview

This project focuses on:
- Translating a Figma design into a functional web page.
- Practicing modern HTML5 structure and semantic elements.
- Using CSS3 for styling, layout, and responsiveness.
- Implementing hover states and mobile responsiveness.

The page is fully responsive and adapts when the screen width is **480px or less**.

---

## 🖼️ Design Reference

The Figma design provided contains all the layout, fonts, and colors.  
You should duplicate the project in Figma to your drafts to inspect elements and extract spacing, color codes, and typography.

---

## 🧩 Features

- Fully responsive web layout.
- Hover interactions on buttons and links.
- Custom fonts and colors.
- Mobile-friendly navigation and sections.
- Centered content with a maximum width of **1000px**.
